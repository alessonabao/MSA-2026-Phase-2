# En Garde Auckland: Project Brief & Development Specs

## 1. Project Overview
**En Garde Auckland** is a high-fidelity web application designed for a premier fencing club. The platform serves as a community hub for discovery, member onboarding, and resource management, catering to both competitive fencers and beginners.

### Brand Identity
*   **Design Philosophy**: Minimalist, high-contrast, and professional.
*   **Primary Palette**: 
    *   Brand Blue: `#214576`
    *   Charcoal (Dark Mode): `#1a1c1e`
    *   Off-White (Light Mode): `#f8f9fa`
*   **Typography**: Hanken Grotesk and Montserrat.

---

## 2. Core Functional Requirements

### A. Event Discovery & Management
*   **Feed**: Scrollable vertical feed of club events.
*   **Advanced Filtering**: Keyword search, Weapon Type (Foil, Epee, Sabre), Event Type, Skill Level, and a dynamic Calendar picker.
*   **Event Details**: Deep-dive pages including registration, venue mapping (Hiwa Regional Centre), and community discussion threads.

### B. Beginner Resources Portal
*   **Weapon Masterclass**: Technical specs for Foil, Epee, and Sabre.
*   **Visual Learning**: Interactive footwork guides and equipment checklists.
*   **Advanced Glossary**: Fencing terminology (Riposte, Flèche, Piste) with custom illustrative icons.

### C. Member Experience
*   **Member Profile**: Participation-focused dashboard tracking club attendance, badges (e.g., 'Century Club'), and skill levels.
*   **Authentication**: Simplified login/signup with resource-focused onboarding for non-members.

---

## 3. Design System (Tokens)
- **Surface**: `#f8f9fa` (Light) / `#1a1c1e` (Dark)
- **Primary**: `#214576`
- **Action**: `#d4af37` (Gold)
- **Border Radius**: `rounded-xl` (12px) - Shadcn UI inspired.
- **Grid**: 4-column layout for desktop discovery.

---

## 4. Development Roadmap
1. **Phase 1**: Core Event Discovery and Filtering Sidebar.
2. **Phase 2**: Beginner Onboarding and Video-First Resource Portal.
3. **Phase 3**: Social Integration (Discussions, Profiles, Attendance Badges).
4. **Phase 4**: Theme Management and Multi-Mode Synchronization.
